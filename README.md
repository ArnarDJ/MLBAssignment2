## Github structure
There are 4 main notebooks, one for the VAE, another for the VQ-VAE, and then a notebook for the analysis and graph making for saved models of each model type. 

### .ipynb Notebooks

#### VAE.ipynb
Contains the code, functions, model arcitecture and training functions for the VAE implimentation

#### VQVAE.ipynb
Contains the code, functions, model arcitecture and training functions for the VAE implimentation

#### Analysis_and_graphics.ipynb
Loads in the models from final production runs and uses the saved models and infomation to prduce analitical graphs and compiled results from the training.


### Final models and Kaggle runs
The final runs and saved models can be found in the folder `Kaggle >> Kaggle_run_final` in the designated folder for that model and training dataset.
There you can find the final models, the code as it was run, and log of the run
